# 📂 Sobre dados do projeto

Esta pasta é reservada para armazenar os dados utilizados no projeto **Scrum-SquadPerformance**.  
Por motivos de **LGPD, ética e confidencialidade**, nenhuma tabela Fato, Dimensão ou De X Paras, será versionado neste repositório e no código as representações nominais estão suprimidas e codificadas.

---

## 📁 Estrutura 

Embora as tabelas não estejam presentes, a estrutura lógica da pasta segue o padrão de projetos analíticos:

- **raw/** — Dados brutos (suprimidos no código)
- **processed/** — Dados tratados e derivados (não versionados)
- **dictionary/** — Listas de termos, stopwords e dicionários auxiliares (somente arquivos não sensíveis)

---

## 🔒 Política de Dados

- Nenhum dado pessoal, sensível ou confidencial é armazenado aqui.
- Os notebooks utilizam caminhos relativos para acessar dados **locais**, mantidos apenas no ambiente do desenvolvedor.
- Qualquer dado utilizado para demonstração deve ser **anonimizado** ou substituído por amostras sintéticas.
