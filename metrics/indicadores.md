# 📌 Indicadores Utilizados

## 🏗️ Indicadores de negício (métrica própria do RA)
- % Concluído = Contagem de cards movidos para status Done
- Contagem String = Volume de String Done no distinct ID
 
## 📈 Indicadores de Performance
- Area Path: Caminho do card contendo Squad, Quarter, Sprint, PM, Dev
- Assigned TO: Responsável pela Task
- Work Item ID: ID único da task
- Work Item Type: Classificação tipo de demanda
- Data Creation: Data que a Task foi estimada no Board
- Data Done: Momento que a tarefa foi concluída

## 📈 DE X PARA e dependências da integração PowerBI e AzureDevops
- DE x PARA de travas: Travas oriundas da Squad, stakeholder, débito técnico registrado em outro arquivo (Join na BD)
- Esforço da trava: Ponderação do esforço estimado versus esforço sentido

> Esses indicadores são utilizados para monitoramento contínuo, priorização de ações e validação de impacto.
