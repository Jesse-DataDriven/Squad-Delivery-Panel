# 🖼️ Exemplos do Frontend (Power BI)

Esta pasta contém **imagens ilustrativas** das telas e visuais desenvolvidos no Power BI para o projeto **Scrum-SquadPerformance**. O objetivo é demonstrar a interface, o design e a lógica visual aplicada no painel, sem expor dados sensíveis ou informações protegidas.

---

## 🔒 Sobre LGPD e Acesso ao Painel

Por motivos de **LGPD, confidencialidade e ética**, nenhum dos seguintes itens será disponibilizado neste repositório:

- Arquivos **PBIX**
- Arquivos **PDF** ou **PPT** exportados do painel
- Links diretos ou réplicas do **Power BI Workspace**
- Dados reais utilizados na construção dos visuais
- Dados de integração com AzureDevops

Somente **imagens estáticas ou animações ilustrativas** e **exemplos visuais anonimizados** são mantidos aqui, garantindo transparência sem comprometer segurança ou privacidade.
